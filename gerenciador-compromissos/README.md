# Gerenciador de Compromissos

Aplicativo mobile local para controlar compromissos, agenda e organização pessoal.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro
- LocalStorage para persistência local

## Estrutura

```text
gerenciador-compromissos/
├── index.html
├── styles.css
├── script.js
├── manifest.json
└── README.md
```

## Como executar localmente

1. Abra o terminal na pasta do projeto.
2. Execute:

```bash
cd "C:\Users\a92319672\UC8-MOBILE\gerenciador-compromissos"
python -m http.server 8000
```

3. Acesse no navegador:

```text
http://localhost:8000/
```

## Funcionalidades

- Resumo do dia
- Agenda com calendário
- Cadastro, edição e exclusão de compromissos
- Marcação de concluídos
- Filtros por todos, pendentes e concluídos
- Pesquisa por título
- Persistência local em localStorage

## Observação

Este projeto foi pensado para execução local e não depende de serviços externos ou hospedagem.
